# 1. Linear Search

## Pattern
Sequential search.

## Approach

Start from the first element and check every element one by one.

If the target is found, return its index.

If the loop finishes without finding the target, return -1.

## Complexity

Time: O(n)
Space: O(1)

## Key Takeaway

Linear Search works on both sorted and unsorted arrays.

Use it when:

- The array is small.
- The array is unsorted.
- You only need a simple search.

Basic idea:

Check → Move → Check → Move
