## Important Concepts

- Strings are immutable in Java
- Use StringBuilder for frequent modifications
- Use charAt() to access individual characters
- Use char[] when modifying characters
- Use frequency arrays for character counting
- Use two pointers for many string problems

## Key Pattern

String problems often involve:

1. Traverse the string
2. Compare characters
3. Modify or build a result
4. Use built-in methods when appropriate
5. Optimize with arrays / two pointers when needed
